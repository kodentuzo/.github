# Kodentuzo

Open-source projects built around Kodentuzo Studio, a self-hosted app for small teams.

Early days: Studio works for projects, files and finances, and most of the rest is
still being built.

| Repository | What it is | License |
| --- | --- | --- |
| [studio](https://github.com/kodentuzo/studio) | Self-hosted app for a small team's projects, files and finances. | AGPL-3.0-only, or commercial |
| [auth](https://github.com/kodentuzo/auth) | Accounts and sign-in for Kodentuzo. People sign in here once, and Studio signs them in through it. | Apache-2.0 |
| [gear](https://github.com/kodentuzo/gear) | Small tools for packaging a web app: metadata, icons and container images. | Apache-2.0 |
| [tones](https://github.com/kodentuzo/tones) | Themes for shadcn/ui apps. | MIT |
| [blanks](https://github.com/kodentuzo/blanks) | Starter templates for apps that run on Kodentuzo Studio. | 0BSD |
| [demos](https://github.com/kodentuzo/demos) | Example apps that run on Kodentuzo Studio. | MIT |
| [manual](https://github.com/kodentuzo/manual) | Documentation for the Kodentuzo projects. | CC BY 4.0 |
